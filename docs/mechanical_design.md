### Microcontroller & Sensor system (wiring & Assembly)

The central control board uses 3 Dinkle Assembly Kits (DK2.5N-GN) DIN rail terminal blocks, along with a DIN Rail Mount Screw Terminal Block Adapter Module, for the Arduino MEGA-2560 R3.

* **Microcontroller Mount:** DIN Rail Mount Screw Terminal Block Adapter Module (hot-swappable).
* **Sensor/Actuator Terminals:** DIN rail screw terminal blocks.
* **Power Distribution:** Common 5V and GND copper bus lines on DIN rail terminal blocks via jumpers.
* **Wiring Standard:**
  * **Power/GND:** 22 AWG stranded wire.
  * **Signals (Sensors/Actuators):** 22 AWG stranded wire.
