### Main PCB / Perfboard Interface

The central control board uses a custom soldered perfboard acting as a breakout shield for the Arduino MCU:

* **Microcontroller Mount:** Dual female header strips (hot-swappable).
* **Sensor/Actuator Terminals:** 2-pin and 3-pin PCB screw terminal blocks.
* **Power Distribution:** Common 5V and GND copper bus lines on perfboard.
* **Wiring Standard:**
  * **Power/GND:** 18/20 AWG stranded wire.
  * **Signals (Sensors/Actuators):** 22/24 AWG stranded wire.
